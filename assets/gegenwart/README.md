# Gegenwart – Bausteine (Bundle)

`bundle.css` und `bundle.js` stammen unverändert aus dem Designsystem **Gegenwart** (Version vom 26.10.2026), übernommen aus dem GGK-Labor (Einheit Nationalsozialismus, M23). Die Farben laufen über Tokens (`--grund`, `--text`, `--petrol`, `--oxid`, `--kuli` …); jede Seite setzt diese Tokens auf die Farben des Psycho-Labors. Farben, Wortmarke und Metapher von Gegenwart wandern nicht mit – nur die Bausteine.

Erste Nutzung im Psycho-Labor: `src/ds05-andere.html`, Fassung 2 (Wahl mit gestufter Rückmeldung, Balken, Bewegungshelfer, Schalter »Weniger Bewegung«).

Bekannte Eigenheit: `wahl` lässt eine leere Begründung zu; die Seite prüft deshalb selbst mindestens 8 Zeichen.
